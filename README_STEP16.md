# FlightSmart Step 16 — Evidence-led Ranking

- Itineraries with BTS historical evidence rank ahead of options without historical evidence.
- LIMITED/LOW market context is ranked below stronger carrier/route evidence.
- UNAVAILABLE historical confidence is no longer assigned a numbered FlightSmart rank.
- Unavailable-history flights remain visible as **Reference options / 参考候補** for price, duration, and connection comparison.
- The Recommended card selects an evidence-backed ranked choice whenever one exists.
- Missing history is not treated as poor performance or a zero score; it is treated as insufficient evidence.
